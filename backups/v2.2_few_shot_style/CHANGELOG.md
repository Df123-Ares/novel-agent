# v2.2 few-shot 风格一致性版本

## 版本信息
- 日期：2026-08-13
- 提示词版本：2.2.0
- 验证模型：qwen2.5:7b-instruct (Q4, 6GB VRAM)

## 本次变更

### 1. Few-shot 风格示例注入
- 新增 `FEW_SHOT_SAMPLE_CHARS=600` 配置
- 从已确认章节的开头抽取 600 字作为风格锚点
- 在 `_build_chapter_context` 中自动注入【风格示例】区块
- 第1章无前文时自动跳过，第2章起自动生效

### 2. 字数达标强化
- `WRITER_MIN_WORDS_RATIO` 从 0.7 → 0.9（下限从 1750 字 → 2250 字）
- 提示词从"约2500字"改为"必须达到2500字"
- 新增扩写指引：环境描写/心理活动/对话延展/动作细节

### 3. 章节标题双重序号修复
- 提示词层面：禁止 LLM 在 title 中生成"第X章"序号
- 代码层面：`_clean_chapter_title()` 兜底清洗序号前缀
- 支持：第X章/回/节/卷/部/篇 + Chapter X

### 4. 大纲 sort_order 全局递增修复
- `_persist_outline_tree` 从 enumerate 局部计数改为全局递增
- 修复不同 arc 下章节 sort_order 重叠导致的交错排序问题
